# MeloX Remote Config Public

Signed public remote compatibility configuration for the official MeloX Android client.

Files in this repository are generated by the private MeloX control repository. `v1/latest.json` must not be edited manually. This repository contains no user data, account credentials, private signing keys, or executable remote code.

`v1/update.json` is the public static release manifest used by the Android client's update checker. Keeping release discovery static avoids unauthenticated GitHub API rate limits.
